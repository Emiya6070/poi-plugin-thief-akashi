# 明石小偷

poi 插件，提供明石／野崎独立计时窗口，可调整字号和分别显示两种计时。

## poi 版本兼容

0.3.3 使用 poi 11 和 12 共有的 `views/env-parts/config` 配置入口，修复 0.3.2 在 poi 11 上初始化失败、无法打开窗口的问题。设置的存储键保持不变。

已核对 poi 11.1.0 源码和本机 poi 12.0.1 的配置接口，并通过模拟宿主的加载、配置读取、游戏事件、弹窗及卸载／重载测试。尚未完成两版客户端内的实际游戏验证。
